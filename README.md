# Trafik Isiginda Felsefe Yapan Yaya

> **Resmi aciklama:** Bu depo, kentsel hareketlilik, varolusculuk ve yaya haklari uzerine yapilan disiplinlerarasi bir arastirma prototipidir.
> **Gercek aciklama:** Kirmizi isikta duran birinin kafasindan gecen saçmaliklari ekrana basar.

## Neden bu proje var?

Cunku asansor muzigi yetmedi. Cunku beklerken bir sey yapmak lazim. Cunku evren bize kirmizi yakti ve biz de ona karsi bir Python dosyasi yazdik.

Bu yazilim:

- kirmizi isikta **gercekten** bekler (time.sleep ile, evet bilimsel)
- rastgele felsefi kriz uretir
- yesil yaninca her seyi unutur (insan gibi)
- sari isikta kararsiz kalir (yine insan gibi)

## Kurulum

```bash
python3 yaya.py
```

Baska bagimlilik yok. Sadece Python 3 ve biraz sabir.

## Kullanim senaryolari

1. Otobus duraginda hava atmak icin.
2. Toplantida "ben aslinda dusunuyorum" demek icin.
3. Kedinin onunde entelektuel gorunmek icin.
4. Copilot'a "bu kod neden var?" diye sormak icin.
